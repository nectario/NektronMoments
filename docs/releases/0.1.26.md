# Nektron Moments 0.1.26

- Full nonmodal Settings workspace with AI & processing, Appearance and Browsing.
- Always-visible AI pricing in Settings and the processing window.
- One setup/progress window, with AI checkbox, model, limit, and Start.
- Reset Order clears the current view's saved custom order and restores newest
  first without modifying original media.
- Native scrollbar input plus a gesture-scoped compositor refresh boost on
  supported Windows systems, and lighter render-aligned thumbnail publication.

There is no fixed application FPS cap on scrollbar dragging. Refresh boosts are
requests to Windows, not display-setting changes or a promise of 120 FPS.
Rendering callback cadence is not GPU-present FPS. Tests do not start paid AI
processing or modify the user's saved photo ordering.

## Validation notes

- 951 C# policy assertions and 127 native workflow checks passed, including the
  57-sample mixed-operation audit. Settings and processing layouts were visually
  reviewed in generated screenshots, including the smaller dark processing view.
- Windows reported an RTX 4090 display at 120 Hz and accepted the compositor
  boost request. This does not establish the application's GPU-present rate.
- Real-library probes used 144,881 items and small thumbnails. The initial probe
  measured about 38 XAML render callbacks/sec; an eight-second warm-up followed
  by another measured pass produced about 40 callbacks/sec with no new decodes.
  UI dispatch wait p95 was approximately 35–39 ms. Dense-grid scrolling therefore
  still needs further performance work; this release does not claim sustained
  120-FPS scrolling. The probes use native scroll automation, not physical mouse
  replay or a GPU presentation trace.
- Neither probe changed the saved photo arrangement or started paid jobs.
- Final release checks passed: 494 Python tests, 951 C# assertions, 127 native
  workflow checks on both published and installed copies, and install/reconnect/
  launch/uninstall canary. Signed installer: `installer/NektronMoments.Setup.0.1.26.exe`.
