# Nektron Moments 0.1.25

Settings now includes the AI assets-per-source limit (1–64, default 64), a
Terra/Luna/Sol scene-model selector (Terra default), and a live illustrative cost
preview. Both Full startup and manual processing use the selected settings.

Process metadata now shows a Start/Cancel dialog with AI checked by default.
The Settings gear reopens reliably and Edit → Settings is available. Screenshot
filtering also recognizes text-based website captures from existing metadata.

Cost estimates use 2,560 input and 100 output tokens per description, standard
USD rates verified 2026-09-21 at https://developers.openai.com/api/docs/pricing.
They exclude geocoding/AWS costs, retries and previously queued jobs; Flex/cache
reuse can cost less. Estimates are not quotes or spending caps.

Server changes add an allowlisted descriptionModel on enrichment preparation
and worker provider selection. Rates and reservations are server-owned. The
existing monthly budgets and completed-result reuse remain in force. No schema
migration or credential change is needed. Deployment alone does not authorize a
paid test or override the production enrichment pause.

Verification uses isolated databases, fake providers and native control checks.
No paid model comparison or live photo enrichment is part of verification.
