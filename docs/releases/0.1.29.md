# 0.1.29 — Readable Settings pricing

This candidate was not published separately. Its pricing changes are included
in the verified, signed 0.1.30 installer; see [0.1.30 release notes](0.1.30.md).

Settings now separates model rates from the selected run estimate:

- Native three-column table: model, input per million tokens, output per million
  tokens. USD amounts are right aligned and use consistent decimal formatting.
- Prominent live estimate for the selected model and allowance, explicitly per
  source. Sub-cent estimates retain additional precision rather than showing free.
- Assumptions, verified date and exclusions are visible separately from the rates.
- The estimate stacks below the table at narrower widths. Both themes are
  rendered in native checks; pricing remains visible when switching Settings tabs.
- Correct the obsolete startup help text describing 64 as a server run ceiling.

No rate, budget, provider, server, or processing behavior is changed. No paid
processing is started by validation. The existing processing window's pricing
presentation is unchanged; this release addresses the Settings screenshot.
