# Artwork and provenance

New Moment Frame artwork, media-specific icons, layouts and brand materials were
created for Nektarios / Nektron, Inc. in this conversation. Common command icons
are carried over from the user’s Nektron Mail v1.2 package; each is identified in
ICON_MANIFEST.json. This is not a third-party icon library or an official Apple,
Microsoft or Google logo package. No store-platform logos are used as app icons.

Logo text was converted to outlines using the installed Inter Display font.
No font binary is distributed. Interface/document typography may fall back to
platform fonts. Platform-specific marks/SDKs remain their owners' property.
No trademark search or legal clearance of “Nektron Moments” has been performed.

The supplied ImageTracker description is summarized only for product boundaries;
its source code, credentials and complete technical README are not redistributed.
The package does not modify a GitHub repository, application, account or service.
