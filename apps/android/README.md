# Nektron Moments for Android

This boundary is reserved for the native Jetpack Compose app, alongside Windows
and iOS. The first
mobile implementation will use MediaStore, WorkManager, Room, Keystore tokens,
Local-first rendering, and the versioned OpenAPI contract.

No generated project is committed until the API contract and Nektron visual
identity inputs are ready for mobile implementation.

Use the [Nektron Moments brand handoff](../../Brand_Images/README.md) for family
references. Adapt typography, touch targets, navigation, and icon exports to
Android; desktop pixel and pane dimensions are not mobile defaults.
