# Nektron Moments for iOS

This boundary is reserved for the native SwiftUI app, alongside Windows and
Android. The first mobile
implementation will use PhotoKit, a persistent local sync queue, Keychain
tokens, Local-first rendering, and the versioned OpenAPI contract.

No generated project is committed until the API contract and Nektron visual
identity inputs are ready for mobile implementation.

Use the [Nektron Moments brand handoff](../../Brand_Images/README.md) for family
references. Adapt typography, touch targets, navigation, and icon exports to iOS;
desktop pixel and pane dimensions are not mobile defaults.
